Mood-Based Music Recommendation System :

A Machine Learning project that detects a user's facial emotion and recommends music based on the detected mood. The system uses a pre-trained emotion recognition model with OpenCV for face detection and provides song recommendations through a simple Gradio interface.

Features

- Detects facial emotions from an image.
- Uses a deep learning model for emotion classification.
- Recommends songs based on the detected emotion.
- Interactive Gradio web interface.
- Runs easily in Google Colab.
  
Supported Emotions

The model recommends songs for emotions such as:
- Happy
- Sad
- Angry
- Fear
- Surprise
- Neutral
- Disgust
